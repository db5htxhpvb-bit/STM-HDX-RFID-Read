# PCB README

This directory will contain PCB layout files and gerbers. Planned layout constraints:
- Board size: 100 mm x 40 mm
- 4-layer stackup: Top, GND, 12V, Bottom
- Copper thickness: 1 oz (default); use multiple thermal vias for power MOSFET pads
- Keep RX front-end away from H-bridge high-current loop

Deliverables to be added:
- kicad/STM-HDX-Reader.kicad_pcb (PCB file)
- gerber/ (Gerber files)
- assembly/ (placement and BOM for assembly)
